## Этап 22. Первый прототип держателей контактов

Цель простая: контактные пластины должны лежать на торцах батареи, а пружина — давить на аккумулятор. Сейчас не делаем точную фиксацию мелких выступов. Для первого прототипа оставим пластинам небольшой карман и проверим посадку физически.

- **22.1.** Больше ничего измерять сейчас не нужно. Уже известных размеров достаточно: пластины шириной 13 мм, минусовая — 10 мм высотой, плюсовая — 12,1 мм.
- **22.2.** Нажми **Ctrl+S**. На следующем шаге создадим по одному простому пазу под каждую пластину. Фиксирующие выступы и ушки добавим после первой примерки.

## Этап 23. Зазор для простых пазов

Пазы будут открыты в сторону большого бокового окна: пластину можно вставить до установки шасси в гильзу. Гильза закроет эти отверстия снаружи.

- **23.1.** В `Parameters` добавь три строки. Подпись — в A, значение — в B, alias назначь ячейке B.

| Строка | Подпись в A | Значение в B | Alias |
| --- | --- | --- | --- |
| 44 | Зазор паза контакта | `0.2 mm` | `ContactPocketClearance` |
| 45 | Глубина минусового паза | `=NegativePlateEnvelope + ContactPocketClearance` | `NegativePocketDepth` |
| 46 | Глубина плюсового паза | `=PositivePlateThickness + 2 * ContactPocketClearance` | `PositivePocketDepth` |

- **23.2.** Проверь: B45 = **1,1 мм**, B46 = **0,75 мм**. **Ctrl+S**.

## Этап 24. Вырезать два простых паза

- **24.1.** В 3D-виде оставь видимым `ChassisSpring`. Покажи `NegativeContact` и `PositiveContact`; им поставь **View → Transparency = 70**, чтобы видеть совпадение с пазами.
- **24.2.** Создай **Part → Primitives → Cube** → `NegativePocketTool`. Введи:

| Свойство | Выражение |
| --- | --- |
| Length | `<<Parameters>>.ContactPlateWidth + 2 * <<Parameters>>.ContactPocketClearance` |
| Width | `<<Parameters>>.ChassisDiameter / 2 + <<Parameters>>.NegativePlateHeight / 2 + <<Parameters>>.ContactPocketClearance + 1 mm` |
| Height | `<<Parameters>>.NegativePocketDepth` |
| Position x | `-(<<Parameters>>.ContactPlateWidth / 2 + <<Parameters>>.ContactPocketClearance)` |
| Position y | `-(<<Parameters>>.NegativePlateHeight / 2 + <<Parameters>>.ContactPocketClearance)` |
| Position z | `<<Parameters>>.NegativeContactZ - <<Parameters>>.NegativePocketDepth` |

- **24.3.** Выдели сначала `ChassisSpring`, затем с Ctrl `NegativePocketTool` → **Part → Boolean → Cut**. Назови результат `ChassisNegativePocket`.
- **24.4.** Создай второй **Cube** → `PositivePocketTool`. Введи:

| Свойство | Выражение |
| --- | --- |
| Length | `<<Parameters>>.ContactPlateWidth + 2 * <<Parameters>>.ContactPocketClearance` |
| Width | `<<Parameters>>.ChassisDiameter / 2 + <<Parameters>>.PositivePlateHeight / 2 + <<Parameters>>.ContactPocketClearance + 1 mm` |
| Height | `<<Parameters>>.PositivePocketDepth` |
| Position x | `-(<<Parameters>>.ContactPlateWidth / 2 + <<Parameters>>.ContactPocketClearance)` |
| Position y | `-(<<Parameters>>.PositivePlateHeight / 2 + <<Parameters>>.ContactPocketClearance)` |
| Position z | `<<Parameters>>.PositiveContactZ` |

- **24.5.** Выдели сначала `ChassisNegativePocket`, затем с Ctrl `PositivePocketTool` → **Part → Boolean → Cut**. Назови результат `ChassisContacts`.
- **24.6.** Выдели `ChassisContacts` → **Part → Check geometry → Run check**. Ожидаем **Solids = 1** и отсутствие ошибок. Временно поставь ему **Transparency = 80**: обе пластины должны лежать в пазах. **Ctrl+S**.

Пазы снаружи будут видны только до вставки шасси в гильзу. На первой примерке проверим, удерживает ли батарея пластины достаточно надёжно; тогда решим, нужны ли защёлки.

## Этап 25. Положение USB-C

Цель: получить три размера, чтобы сделать проём точно напротив разъёма. В FreeCAD пока ничего не меняем.

- **25.1.** Измерь ширину и высоту металлического USB-C разъёма.
- **25.2.** Измерь расстояние от центра USB-C до ближайшего края блока плат по вертикали.
- **25.3.** Пришли три значения в таком виде:

```text
USB-C: ширина … мм; высота … мм
Центр USB-C от ближайшего края блока плат: … мм
```

После этого сделаем прямоугольный проём с печатным зазором и привяжем к нему шторку.

<a id="stage-26"></a>

## Этап 26. Макет проёма USB-C

Сначала ставим куб, который покажет будущую дырку. Его пока **не вырезаем**: `Electronics` — только габаритный блок, без точной формы разъёма.

**Ориентация зафиксирована:** сторона `+Y` — верх и сторона вставки «бутерброда» плат. USB-C выходит сюда же через открытый паз. Сторона `-Y` — низ: под батареей пойдёт антенный кабель.

- **26.1.** Перейди в **Part**. Скрой `Sleeve` и `ChassisContacts`. Покажи `Electronics`. Создай **Part → Primitives → Cube**, назови `USBWindowTool`.
- **26.2.** Во вкладке **Data** задай:

| Свойство | Значение |
| --- | --- |
| Length | `10 mm` |
| Width | `4.3 mm` |
| Height | `6 mm` |
| Position x | `-5 mm` |
| Position y | `<<Parameters>>.BoardThickness / 2 - 3.8 mm` |
| Position z | `<<Parameters>>.SleeveLength - <<Parameters>>.FrontSpace - 1 mm` |

10 × 4,3 мм — USB-C 9 × 3,3 мм плюс по 0,5 мм на сторону для печати. Куб должен лежать у верхнего края переднего торца блока плат; его ось совпадает с центром USB-C: 1,65 мм ниже верхней поверхности платы.

- **26.3.** Поставь `USBWindowTool` **View → Shape color** в яркий цвет и `Transparency = 40`. Нажми **0**, затем поверни модель к USB-торцу. Куб должен выходить за передний торец `Electronics` и находиться у его верхнего края.
- **26.4.** Скрой `Electronics`. Покажи `ChassisContacts`; `Sleeve` можно показать с прозрачностью 80. Выдели сначала `ChassisContacts`, затем с Ctrl `USBWindowTool` → **Part → Boolean → Cut**. Результат назови `ChassisUSB`.
- **26.5.** Выдели `ChassisUSB` → **Part → Check geometry → Run check**. Ожидаем `Solids = 1` и без ошибок. Покажи `Electronics`: USB-торец должен быть виден через новое отверстие. **Ctrl+S**.
- **26.6.** Проём должен быть открыт до верхнего края шасси, иначе «бутерброд» плат не вставится. Раскрой `ChassisUSB` в дереве и покажи `USBWindowTool` только для ориентира. Создай второй **Part → Primitives → Cube** → `USBEntryTool`.
- **26.7.** У `USBEntryTool` задай:

| Свойство | Значение |
| --- | --- |
| Length | `10 mm` |
| Width | `<<Parameters>>.ChassisDiameter / 2 - <<Parameters>>.BoardThickness / 2 + 1 mm` |
| Height | `6 mm` |
| Position x | `-5 mm` |
| Position y | `<<Parameters>>.BoardThickness / 2` |
| Position z | `<<Parameters>>.SleeveLength - <<Parameters>>.FrontSpace - 1 mm` |

Этот куб соединяет отверстие USB-C с верхним внешним краем. При текущих размерах его ширина будет **6,2 мм**.
- **26.8.** Выдели сначала `ChassisUSB`, затем с Ctrl `USBEntryTool` → **Part → Boolean → Cut**. Назови результат `ChassisUSBSlot`.
- **26.9.** Проверь `ChassisUSBSlot` через **Part → Check geometry**: `Solids = 1`, без ошибок. С USB-торца должен получиться открытый П-образный паз. **Ctrl+S**.

## Этап 35. Пробная печать и примерка

Детали лежат в `stl/`, уже в положении для печати; G-code для пробной печати — в `gcode/`. После правок модели оба набора устаревают. Настройки экспорта: FreeCAD 1.1.3, LinearDeflection 0,02 мм, AngularDeflection 10°, для шасси 0,05 мм и 12°, скрипт `scripts/export_stl.py`.

| Файл | Положение | Поддержки |
| --- | --- | --- |
| `xiao_wio_case_v2_chassis.stl` | лёжа, окном вверх: пазы контактов становятся вертикальными стенками | нужны, только от стола |
| `xiao_wio_case_v2_sleeve.stl` | стоя, бортиком на столе: нет свесов, отверстие круглое | не нужны |
| `xiao_wio_case_v2_board_clamp.stl` | плоской стороной на столе | не нужны, короткий свес у языка |
| `xiao_wio_case_v2_shutter.stl` | фланцем на столе: лицом вниз фланец висит в воздухе | не нужны |

Нарезка: PrusaSlicer 2.9.6, Creality Ender-3, сопло 0,4 мм, слой 0,2 мм, Generic PETG (240/70 °C), у шасси и гильзы кайма 6 мм. Сетки `manifold = yes`. Всего около 67 г и 8 ч 20 мин. Послойно смотрели только отдельные слои. Сначала стоит напечатать вставку и шторку: они быстрые и сразу покажут зазоры.

**Сборка**

1. Припаяй провода к ушкам контактов, заведи ушки в колодцы вниз и приклей пластины к плоским стенкам.
2. Заведи антенный разъём из паза изнутри, гайку наверни снаружи в выемке грибка. Выемка Ø12 мм, глубина 3,5 мм: нужна торцевая головка на 8 мм.
3. Проложи провода и антенный кабель по пазу и через подъём к платам. Припаяй провода, подключи антенну.
4. Вставь блок плат сверху, разъём USB-C попадает в окно торца. Сверху положи прижимную вставку, её язык закрывает паз над USB-C.
5. Надень кольцо 29 × 1,5 мм на канавку у грибка, вставь батарею: устройство сразу включится.
6. Вставь диск в гильзу с заднего конца до бортика. Вставь шасси USB-концом вперёд, совмести выступы с пазами и поверни шасси на 40° по часовой стрелке, если смотреть со стороны антенны, до затяжки.
7. Диск поворачивается за прорезь на торце. Открыто: окно напротив порта. Закрыто: поворот на 180°.

**Что проверить на примерке**

- Антенна накручивается до конца: резьба 11 мм, стенка 5,4 мм, гайка принята 2 мм, свободно около 3,6 мм. Глубже выемку делать нельзя: она прорежет грибок.
- Байонет: усилие затяжки и самоотвинчивание, крепость выступов. Кольцо 29 × 1,5 мм, канавка Ø29,6 × 2 мм.
- Передний упор блока плат: при выдёргивании штекера блок держат вставка и концы прорезей под штыри.
- Пружина минуса при рабочей высоте 2 мм: не сжимается ли она до упора.
- Диск: не слишком ли туго идёт, держат ли фиксаторы.
- Прижим плат вставкой: зазор 0,1 мм рассчитан по габаритному блоку.
- Проход проводов и антенного кабеля через подъём и выход за платами. Кабель Ø2 мм идёт практически прямо, до батареи около 1,2 мм.
- Посадку Wio на дно отсека и штыри в прорезях: прорезь 1,6 мм, кончики штырей на 0,5 мм от гильзы.
- Крепость проушины и размер отверстия Ø6 мм под твой карабин или шнур.

## Этап 33. Проушина, отвод кабеля, блок плат — выполнен

Скрипты: `apply_rear_lug.py`, `apply_cable_exit.py`, `apply_board_model.py`, `apply_lower_boards.py`, `apply_open_cable_slot.py`. Проверка: `check_stage_29_32.py`. Снимки: `renders/sections.png` и `renders/rear_*.png`.

- **Проушина** по образцу фото с Printables: плоская, плавно вырастает из торца через вогнутые дуги R5 и R8, контур сужается к концу Ø13 мм. Отверстие Ø6 мм смещено на 0,5 мм от конца, стенка у конца 4 мм, вылет 16 мм, толщина 6 мм, `LugCenterY` = 8 мм. Вместо `RearFlange` и кольца теперь одно тело `RearBody`. Диаметр грибка у гильзы остался полным. Рёбра скруглены R1,5 и R0,8; несколько коротких кромок у основания проушины FreeCAD не скруглил.
- **Блок плат** `BoardStackModel` — модель «XIAO nRF52840 & Wio-SX1262 Kit 3D model», автор zuberio, Printables, лицензия CC0. Только макет, не печатается. Высота 20,5 мм подтвердила замер 21 мм. Блок стоит в отсеке без касаний. В модели штыри на 0,35 мм короче реальных и кабель на 0,4 мм ниже, поэтому проверка считает штыри и кабель по замерам.
- **Спуск блока плат.** Изгиб кабеля мог сдёрнуть U.FL, поэтому блок опущен на 3 мм, штыри не подрезаем. Замеры: штыри 4,35 мм под Wio, центр кабеля 4,5 мм над низом Wio. Кончики штырей стоят на `PinTipY` = −13,5 мм, внутри диаметра шасси, и гильзы не касаются. Wio лежит на поднятом дне отсека (`WioBottomY` = −9,15 мм), штыри входят в прорези `PinSlotTools`. Верх блока теперь `StackTopY` = 7,5 мм, центр USB-C 5,85 мм, вставка стала толще, 8,1 мм.
- **Отвод кабеля.** U.FL стоит на верхней стороне Wio у конца, противоположного USB-C, кабель смещён на 3,6 мм от оси и выходит на Y=−4,65 мм. `BoardGap` = 6 мм. `CableExitTool` открывает выход на всю ширину паза, `CableSlotTool` — сквозной вырез 3,6 мм в полу батарейного отсека на последних 15 мм: стенка там не нужна, батарея лежит на боках ложемента. `AntennaCable` — макет кабеля, минимальный радиус изгиба 58 мм, то есть кабель практически прямой. Клип на U.FL между платами стоит оставить: он защищает от тряски.
- **STL.** На углах скруглений сетка получала мелкие самопересечения; `export_stl.py` чинит их и не записывает файл, пока сетка не чиста.

## Этап 34. Гладкий корпус и открытые контакты — выполнен

Скрипты: `apply_flush_body.py`, `apply_open_contacts.py`, `apply_round_usb.py`, `apply_round_front.py`, `apply_strong_bayonet.py`. Проверка: `check_stage_29_32.py`.

- **Корпус.** `FlangeDiameter` равен диаметру гильзы, ступеней снаружи нет. Ключ, наружный выступ гильзы и старый колпачок удалены.
- **Байонет.** Винтовой: три выступа по 40° (около 11 мм) вместо 22°, подъём 0,4 мм за поворот 40°, в конце поворота грибок подтягивается к гильзе. Опорная кромка паза 0,75–1,15 мм, стенка гильзы над пазом 0,8 мм. Кольцо заменено на сечение 1,5 мм и сдвинуто на Z=2,4 мм, чтобы выступы встали перед ним и задняя стенка не удлинилась: иначе не хватит резьбы разъёма.
- **Передняя стенка у USB-C** 1,5 мм вместо 3,7 мм (`FrontSpace` = 1,8 мм): корпус на 2,2 мм короче, разъём ближе к торцу.
- **Диск.** Гильза длиннее шасси на 3,2 мм, спереди внутренний бортик. Диск `Shutter` вставляется изнутри, лицо заподлицо с торцом, поворот за прорезь, фиксаторы на пружинящих дугах входят в пазы гильзы.
- **Передний торец гильзы.** Наружная кромка скруглена R1,5.
- **Окна USB-C.** Углы скруглены R2: в диске все четыре, в шасси два нижних. Проверка рассчитана на штекер со скруглением корпуса R1; если у твоего углы острее, окно можно подпилить надфилем.
- **Контакты.** Всё между пластинами и батареей вырезано (`NegativeFaceTool`, `PositiveFaceTool`), пластины клеятся к плоским стенкам: минус Z=6,9 мм, плюс Z=80,43 мм. Минус перенесён на 2 мм к батарее: `SpringWorkingHeight` = 2 мм. `WireChannelStartZ` теперь задан числом, чтобы стенка разъёма не менялась. Колодцы 4,5 × 2,6 мм идут сквозь пол в паз проводов и пропускают разъём типа Dupont.

## Этапы 29–32. Антенна, шторка, кольцо, вставка — выполнены

Это проверка по габаритным макетам, не физическая посадка.

Габариты корпуса: длина 132,9 мм вместе с проушиной, диаметр 35 мм.

## Принятые решения по конструкции

- Электроника: XIAO nRF52840 + Wio-SX1262 Kit.
- Аккумулятор: 18650. Контакты: отдельные металлические пластины, одна с пружиной, как у держателей AA.
- Наружный корпус: гладкая цилиндрическая гильза. Резьбовое соединение корпуса не используем.
- Шасси вставляется платами и торцом USB-C вперёд. Этот торец доходит до противоположного конца гильзы; антенный конец входит последним.
- На антенном конце шасси находится расширение в виде «грибка», ограничивающее дальнейшее продвижение к USB-C.
- Ушко для шнура — скруглённая проушина на заднем торце, смещена вверх от антенного разъёма.
- Снаружи гладкий цилиндр Ø35 мм без ступеней, виден только шов у грибка.
- Между шасси и гильзой одно резиновое кольцо 29 × 1,5 мм у грибка.
- Шасси держится в гильзе винтовым байонетом: три широких выступа, поворот 40° с затяжкой. Сплошную резьбу не используем: она съедает стенку 1,5 мм.
- Целевая защита — от брызг. Погружение в воду не является требованием.
- Выключателя нет: вставленная батарея сразу питает устройство.
- USB-C закрывает диск, утопленный в торец гильзы: открыто и закрыто, поворот на 180°.
- Контакты батареи приклеиваются к плоским стенкам, ушки выходят вниз в сквозные колодцы.
- Блок плат прижат печатной вставкой `BoardClamp`, снаружи кнопки и светодиоды не выводим.
- Материал: PETG, сопло 0,4 мм. Зазоры 0,3 мм на сторону сохраняем.
- Батарея смещена вверх (+Y) к окну шасси, под ней проходит паз для проводов батареи и антенны.

## Что ещё нужно определить

- Усилие пружины при принятой рабочей высоте 4 мм, направление ушек и геометрию фиксаторов контактов. Измеренные размеры батареи, плат и контактов записаны в этапе 9.
